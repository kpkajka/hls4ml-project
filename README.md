Project based on tutorial by Jonathon Langford: https://github.com/jonathon-langford/acceleratingai-aims25

The core component of the trigger hardware is an array of FPGAs, which are highly customisable integrated circuits which enable parallel programming, as well as custom compute units. This makes them highly flexible for any application. Neural networks can be implemented onto FPGA hardware using the \texttt{hls4ml} library, which converts \texttt{Keras} NNs into HLS code. An example of FPGA implementation of NNs which classify jets at the CMS detector is introduced. First, a benchmark \texttt{Keras} NN is built and its performance measured. Next, it is converted to FPGA firmare using \texttt{hls4ml} with different fixed-point precisions. Two tuning techniques are explored: quantisation-aware training and pruning, and both were successful in significantly reducing resource usage while retaining global accuracy.
